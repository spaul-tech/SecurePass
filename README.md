# 🔐 SecurePass — Password Security Toolkit

<img width="900" height="600" alt="toolkit-pic" src="https://github.com/user-attachments/assets/b8a2eab9-6473-4ca3-8920-7592425b4f12" />


**SecurePass** is a Python-based password security toolkit designed to generate secure passwords, evaluate password strength, and create memorable passphrases. The project focuses on practical password security concepts, cryptographically secure randomness, password analysis, and clipboard management.

---

## ✨ Features

### 🔑 1. Secure Password Generator
- Generate passwords between 8 and 64 characters.
- Customize password composition:
  - Uppercase letters (A–Z)
  - Lowercase letters (a–z)
  - Numbers (0–9)
  - Special symbols
- Guarantees at least one character from every selected character set.
- Uses Python's `secrets` module for cryptographically secure random generation.
- Automatically analyzes generated passwords.

### 📊 2. Password Strength Analyzer
- Evaluates password length and character diversity.
- Estimates theoretical password entropy.
- Detects common passwords.
- Identifies predictable sequences such as `1234` and `abcd`.
- Detects excessive repeated characters.
- Provides suggestions for improving password security.

**Strength classifications:**
- 🔴 Weak
- 🟡 Moderate
- 🔵 Good
- 🟢 Strong

### 📝 3. Passphrase Generator
- Generates memorable multi-word passphrases.
- Uses the EFF Large Wordlist.
- Supports configurable word counts.
- Offers different word separators.
- Optional word capitalization.
- Displays estimated entropy.

### 📋 4. Clipboard Management
- Copies generated passwords directly to the clipboard.
- Automatically clears the clipboard after 30 seconds.
- Checks whether the clipboard still contains the generated password before clearing it.

## 🔒 Security Notes

- Password generation uses Python's `secrets` module instead of the standard `random` module.
- Password strength and entropy values are estimates, not guarantees of real-world security.
- The clipboard auto-clear feature only clears the clipboard if it still contains the password generated by SecurePass.
- Avoid entering real or sensitive passwords into tools you do not trust.
- Generated passwords should be stored in a reputable password manager.
